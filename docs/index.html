photodyn2p

Model two interacting planets from their transit times, radial velocities and light curves — with a global search for the right orbital configuration, a maximum-likelihood fit, MCMC, and a graphical interface.

Transit timing variations in test example 1: the transits of the inner planet b (blue) arrive up to 80 minutes early or late, those of the outer planet c (orange) up to 9 minutes, in opposite phase and with a 122-day period — the signature of two planets near a 2:1 resonance. What it does

photodyn2p integrates the orbits of two planets with the N-body code TTVFast and compares the predictions with the data. Either planet may transit; a planet that does not transit is found through the timing variations it causes in the other planet and through the stellar radial velocities.

ttv mode

Fits mid-transit times and radial velocities. Fast: thousands of models per second, so the whole range of orbital configurations can be searched.

photodyn mode

Fits the light curves directly, every transit at its own predicted time, with a Gaussian process for starspot variability, together with mid-times and radial velocities.

How an analysis runs

  1. Prefit. Differential evolution searches the orbital configurations on a fast objective, and the best distinct solutions are polished. Two interacting planets have many partial solutions; this step finds the right one.
  2. Maximum-likelihood fit. The full model — transits, timings, radial velocities, stellar noise — is optimised from the prefit solution.
  3. MCMC. emcee samples the posterior distributions; chains can be extended and checked for convergence.

Quick start

Python 3.7 or newer; on Windows use WSL.

git clone https://github.com/svaverbe/photodyn2p.git
cd photodyn2p
python -m pip install -r requirements.txt
python photodyn2p_gui.py examples_synthetic/example1_ttv_both/config.json

On the Run tab, set the start file to truth_start.json and press Check: lnP at the start; the log ends with Start: lnP = 325.60. The manual then walks through four test examples with known answers and a complete recipe for a new system.

photodyn2p uses TTVFast (Deck et al. 2014), batman (Kreidberg 2015), celerite2 (Foreman-Mackey et al. 2017) and emcee (Foreman-Mackey et al. 2013); please cite them with results of this program.
